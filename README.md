# SauceDemo Automation Framework

This project is a web automation framework built using **Selenium WebDriver** and **Java** to automate end-to-end user flows on the SauceDemo website.

The framework is designed using the **Page Object Model (POM)** to improve maintainability, readability, and scalability.

---

## 🚀 Features

- End-to-end test automation for SauceDemo
- Page Object Model (POM) design pattern
- Reusable and maintainable code structure
- Automated user flows including:
  - Login
  - Product selection
  - Add to cart
  - Checkout process
- Easy to extend with new test cases
